# Diamond Investment Card

Create a single reusable React + TypeScript component called DiamondInvestmentCard.

This component is for UI demonstration only.

Do NOT implement backend logic. Do NOT connect APIs. Do NOT modify any existing pages.

Use dummy data only.

Purpose

Create a premium 3D luxury investment card inspired by an exclusive metal debit card.

This is not a pricing card.

The card should immediately feel premium and interactive.

Style

Theme:

Luxury fintech

Futuristic

Dark premium

Glassmorphism

Metallic diamond blue finish

The card should resemble a physical metal card.

Card Size

Desktop: 420px × 260px

Mobile: Responsive while maintaining the same aspect ratio.

Border Radius: 24px

Materials

Use:

Metallic blue gradient

Frosted glass effect

Gloss reflections

Soft glow

Premium shadows

Subtle noise texture

Edge highlights

The card should look expensive.

3D Interaction

The card must exist in a real 3D scene.

Requirements:

Use CSS 3D transforms.

Preserve 3D perspective.

Smooth GPU-accelerated animations.

The card can rotate a full 360° on both the X and Y axes.

Rotation should be smooth and continuous with no snapping.

Users can drag with the mouse (desktop) or swipe (mobile) to rotate the card.

When interaction ends, the card should smoothly return to its default viewing angle.

Include subtle floating motion while idle.

Add gentle mouse parallax and realistic lighting changes as the card rotates.

Do not make the animation too fast.
